Bugs found and fixed in Phase 3:

1. **Context nudges lost their first message and kept him frozen.** The late-night / focus nudge opens the chat
   bubble; if the bubble window did not exist yet it is created lazily, and the `reminder` event fired before the
   page listened: no text. Also: it opened with keyboard focus (the code comment says these must not), and the
   bubble stayed open for ever, and while it is open Glitch stands still (measured: `panelOpen` true for 90 s+, no
   roaming, no further reactions). Fix: `windows::show_bubble_for_message` (unfocused, waits 1.8 s for a freshly
   created page), `Reminder.ambient` so context nudges hide again after 12 s + reading time unless you touched or
   hovered the bubble. Timer reminders use the same unfocused, no-lost-message path (a ringing timer no longer
   steals what you are typing); they stay open until dismissed.
2. `dev/windows-smoke.mjs` moved the **real** `dev.glitch.companion` `settings.json`/`memory.json` aside while it
   ran and killed the app by image name. Now it refuses without `--identifier` of a test copy and only looks at its
   own exe's image name. Also adapted to the per-window command grants (review L4).
3. `dev/update-me-check.mjs` adapted to per-window grants (tries the other windows, opens the panel through the
   mascot's `show_panel` grant).
